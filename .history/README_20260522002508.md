# Demoblaze API testing

This repository contains two different projects for automate API and e2e tests over the Demoblaze website.

## Quick overview:
- API testing was implemented using Karate framework to test endpoints over `https://api.demoblaze.com/`.
- E2E testing was implemented using Serenity framework to test full flows in the `https://www.demoblaze.com/` website.

## Notes
- Each sub repo contains a README file detailing important characteristics and instructions to run the tests.

## Contributing
- If you add tests, try to keep features generic and use similar structure so others can reuse them easily.
